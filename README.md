# MCA Semester 2 - NSA Lab Programs

## Overview

This repository contains the laboratory programs for the **Networking and System Administration (NSA) Lab** course in the **Master of Computer Applications (MCA)** program, **Semester 2**, offered by **Kerala Technical University (KTU)**.

The NSA Lab focuses on practical implementation of shell scripting concepts, file handling, system administration tasks, and basic programming constructs using Bash shell. These programs help students understand Unix/Linux command-line operations, scripting logic, and system-level programming.

## Course Details

- **University**: Kerala Technical University (KTU)
- **Program**: Master of Computer Applications (MCA)
- **Semester**: 2
- **Course**: Networking and System Administration Lab (NSA Lab)
- **Objective**: To provide hands-on experience in shell scripting and system programming

## Programs Overview

The following table lists all the shell scripts included in this lab manual. Each program demonstrates specific concepts and learning objectives.

| File Name | Description | Learning Objective / What We Observe |
|-----------|-------------|-------------------------------------|
| `01.sh` | Script to find the greatest of three numbers entered by the user | Conditional statements (`if-elif-else`), user input handling, comparison operators |

| `03.sh` | Check if a specific user is logged in and count occurrences | Command-line arguments, file redirection, text processing with `grep`, system commands (`who`) |
| `04.sh` | Reverse the contents of a file using `tac` command | File existence checking, file operations, text manipulation commands |
| `05.sh` | Check if a given number is even or odd | Arithmetic operations, modulo operator, conditional logic |
| `06.sh` | Check if a given path is a directory | Path validation, directory checking, user input for file system operations |
| `07.sh` | Count the number of files in a specified directory | Directory traversal, file counting using `find`, command substitution |
| `08.sh` | Reverse a given number | Number manipulation, loops, arithmetic operations |
| `09.sh` | Demonstrate string concatenation in Bash | String variables, concatenation operators, variable expansion |
| `10.sh` | Extract a substring from a given string based on start index and length | String slicing, parameter expansion, user input validation |
| `11.sh` | Display system information including shell, home directory, OS type, and current working directory | Environment variables, system commands (`pwd`), information display |
| `12.sh` | Calculate the factorial of a given number using a loop | Loops (`for`), arithmetic operations, sequence generation |
| `13.sh` | Check if a given number is a palindrome | Number reversal algorithm, comparison logic, palindrome concept |
| `14.sh` | Generate Fibonacci series up to n terms | Sequence generation, variable swapping, iterative algorithms |
| `15.sh` | Reverse a given string | String manipulation, loops, character extraction |
| `16.sh` | Menu-driven file handling operations (copy, print from line, diff, grep) | Menu systems, case statements, file operations, text processing |
| `17.sh` | Display system information: logged users count, file listings, process priorities | System monitoring, command pipelines, text formatting with `cut` |
| `18.sh` | Calculate GCD and LCM of two numbers | Mathematical algorithms, Euclidean algorithm, arithmetic operations |
| `19.sh` | Simple database management system for employee records | File-based data storage, CRUD operations, menu-driven interfaces |
| `20.sh` | File operations demonstration: create, copy, count, extract lines, append | File creation, copying, line extraction with `head`/`tail`/`sed`, word counting |

## How to Run the Programs

1. Ensure you have a Unix/Linux environment or Windows with Bash shell installed (e.g., Git Bash, WSL).
2. Make the script executable: `chmod +x <filename>.sh`
3. Run the script: `./<filename>.sh`
4. Follow the on-screen prompts for input where required.

## Prerequisites

- Bash shell environment
- Basic knowledge of Unix/Linux commands
- Text editor for viewing/editing scripts

## Learning Outcomes

By completing these lab programs, students will:

- Gain proficiency in Bash shell scripting
- Understand conditional and looping constructs
- Learn file and directory operations
- Practice system administration commands
- Develop problem-solving skills through algorithmic implementations
- Understand input/output handling and user interaction

## Notes

- All scripts are written in Bash and may require adjustments for different shell environments.
- Some programs create temporary files; ensure appropriate permissions.
- Test programs in a safe environment to avoid accidental data loss.
